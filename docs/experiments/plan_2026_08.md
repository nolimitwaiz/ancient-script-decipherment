# Working plan — August 2026

Written after two results reframed the project:

1. **The pixel deficit is not a capacity artifact.** Matched-capacity BPE
   (~96M params, same 12/3 shape) reaches 5.587 ± 0.10 vs pixel 5.975 ± 0.098.
   The preregistered "it's capacity" hypothesis is refuted.
2. **The experiment was near-tautological.** Our pixels are
   `render(unicode_text)` — a deterministic, lossy re-encoding that contains
   *no information the text does not already contain*. The pixel arm was
   solving a strictly harder version of the same problem. Salesky's pixel
   advantage was for **multilingual sharing and unseen-script transfer**, not
   single-clean-corpus translation, so our setup never tested their claim.
3. **The SSL objective leaked.** Windows are 24px wide at stride 12, so
   consecutive windows overlap 50%: a randomly masked window is reconstructable
   by copying from its neighbours (~84% of masked windows keep an intact
   neighbour). Training loss 0.005 is the signature. A1 is measuring almost
   nothing.

## Falsifiable predictions (recorded before running)

- **P1**: span-masked MAE (A1b) beats random-masked MAE (A1) on downstream
  pixel CE by ≥0.15 nats. *If false, the overlap leak was not the problem.*
- **P2**: I-JEPA (A2) beats A1b by <0.10 nats. *i.e. most of the gain is the
  masking fix, not latent prediction — glyph "semantics" are the strokes, so
  there is less nuisance detail for latent prediction to discard than in
  natural images.*
- **P3**: on LogogramNLP linearts, the pixel–BPE gap narrows by ≥50% relative
  to font renders. *If false, the pixel hypothesis is in real trouble at this
  data scale regardless of input realism.*
- **P4**: on the sign-held-out split, pixels **beat** BPE, because held-out
  signs have no BPE vocabulary entry while pixels degrade gracefully. *This is
  the strongest pro-pixel prediction we can make and the fairest test of the
  lineage's actual claim.*

## Energy-based note

The decipherment core is already an EBM: entropic-regularised optimal
transport with Sinkhorn is energy minimisation over a constrained coupling,
and the Luo-style constraints (monotonicity, sparsity, frequency matching) are
energy terms. Item 6 adds the second EBM family (score-based) where it fits
naturally — inpainting damaged glyphs.

## Out of scope (recorded so it stays decided)

- **3D / RTI / photogrammetry**: genuinely used in epigraphy for worn carved
  inscriptions, and carving depth disambiguates overlapping signs — but no 3D
  data exists in any corpus we have, and acquisition is a separate project.
  Revisit only if a partner supplies scans.
- **Pretrained checkpoints in the sealed pipeline**: permanently out. Item 5,
  if approved, lives in `contrib/openbook/` and is labelled open-book in every
  table it appears in.

## Update 2026-08-07: the SSL objective was degenerate on two counts

Measured on 3,327 real TLA hieroglyph windows (200 sentences), the MSE of
predictors that learn *nothing*:

| trivial predictor | MSE |
|---|---|
| predict all-white | 0.0344 |
| predict global mean | 0.0296 |
| predict per-window mean | 0.0289 |
| **A1 (random mask), 200 steps** | **0.042** |
| **A1b (span mask), 200 steps** | **0.043** |

Both arms were *worse than trivial*. Renders are ~95% background, so raw pixel
MSE is dominated by empty space and the ~4.5% of pixels carrying strokes
contribute almost no gradient. The masking leak was real, but it was the
second-order problem.

Fixes applied: per-window standardised targets (the MAE paper's
`norm_pix_loss`), which makes the loss read as "fraction of within-window
variance unexplained" — predicting the mean now scores 1.0, so numbers are
interpretable and comparable across runs. Also: the JEPA collapse detector's
warmup was 500 steps while kill-gates run 200, so it never armed in exactly
the runs meant to catch problems; warmup is now 50.

**Method note for the write-up**: "loss went down" is not evidence. Every
generative/reconstructive objective in this project must be reported against
its trivial-predictor baseline, and the tests now enforce the scale.
