## Encodings & notes

- **tla_earlier_egyptian** — unicode hieroglyphs + transliteration. pseudo-documents = non-contiguous dating cohorts (dateNotBefore, dateNotAfter, authors); signs outside Unicode appear as <g>GardinerCode</g> markup (source: https://huggingface.co/datasets/thesaurus-linguae-aegyptiae/tla-Earlier_Egyptian_original-v18-premium)
- **tla_late_egyptian** — unicode hieroglyphs + transliteration. pseudo-documents = non-contiguous dating cohorts (dateNotBefore, dateNotAfter, authors); signs outside Unicode appear as <g>GardinerCode</g> markup (source: https://huggingface.co/datasets/thesaurus-linguae-aegyptiae/tla-late_egyptian-v19-premium)
- **tla_demotic** — transliteration only. pseudo-documents = non-contiguous dating cohorts (dateNotBefore, dateNotAfter, authors); signs outside Unicode appear as <g>GardinerCode</g> markup (source: https://huggingface.co/datasets/thesaurus-linguae-aegyptiae/tla-demotic-v18-premium)
- **coptic_scriptorium** — unicode Coptic. dialect inferred from directory name; token annotations not ingested in Phase 1 (source: https://github.com/CopticScriptorium/corpora)
- **hebrew_morphhb** — unicode Hebrew (pointed, WLC). one record per verse; doc = book; lemma/morph annotations not ingested in Phase 1 (source: https://github.com/openscriptures/morphhb)
- **ugaritic_hebrew_cognates** — transliteration (both sides). file uga-heb.no_spe.cog; fields src=uga, tgt=heb; '|' separates target variants; splits for the ladder are made in Phase 5 protocol (source: https://github.com/j-luo93/NeuroDecipher (Luo, Cao & Barzilay 2019 release))
- **linearb_greek_cognates** — unicode Linear B glyphs vs Greek. file linear_b-greek.cog; fields src=linear_b, tgt=greek; '|' separates target variants; splits for the ladder are made in Phase 5 protocol (source: https://github.com/j-luo93/NeuroDecipher (Luo, Cao & Barzilay 2019 release))
- **logogram_nlp** — mixed: images + per-task text/metadata. inventory-only in Phase 1; task parsing lands with the Phase 7 comparison hooks; .pth pickles deliberately not opened (source: https://github.com/taineleau/logogramNLP)
- **logogram_egy** — hieroglyphic lineart PNG + transliteration. REAL scholarly linearts, not font renders; doc_id = dating cohort; image paths are relative to the corpus raw dir (source: https://github.com/taineleau/logogramNLP (Chen et al., ACL 2024), data/EGY)
- **greek_first1k** — unicode polytonic Greek (EpiDoc TEI). grc editions only; records = TEI <p>/<l> units containing Greek script; doc = textgroup.work (source: https://github.com/OpenGreekAndLatin/First1KGreek)
- **cuneiform_cdli** — ATF transliteration (Sumerian/Akkadian and others; language in meta). one record per tablet; catalogue language/period attached from cdli_cat.csv (source: https://github.com/cdli-gh/data (snapshot 2023-10))
- **meroitic_rem** — ASCII romanization of Meroitic (capitals encode special signs). undeciphered-language frontier target; Embeddings/ dir is pretrained and quarantined (never read); auxiliary vocab/example files kept raw only (source: https://github.com/Joshua-Otten/Meroitic-Corpus (Otten & Anastasopoulos 2025))
- **linear_b_damos** — unicode Linear B. DAMOS (Oslo) and LiBER (liber.cnr.it) are web databases without bulk export; LiBER exposes a CNR SPARQL endpoint (data.cnr.it) worth pursuing. Luo et al.'s linearb_greek_cognates already cover ladder rung 2; see docs/data_gaps.md (source: DAMOS (Oslo) / LiBER (CNR, liber.cnr.it) — no bulk export)
- **mayan** — glyph-block transliterations + images. no open bulk download found (2026-08): MHD requires an application (CSU Chico), mayacorpus.org (200k+ glyph blocks, MHD-sourced) is interactive-only, TWKM/Bonn publishes no public TEI dump — contact the projects; see docs/data_gaps.md (source: MHD (application) / mayacorpus.org (interactive) / TWKM Bonn (no dump))
- **libyco_berber** — transliteration + panel drawings. the LBI database is DEFUNCT (project ended after W. Pichler's death; lbi-project.org domain is now squatted). ~300 panels survive in Wayback snapshots of institutum-canarium.org/lbi-project (use pre-2020 captures); recover via archive scrape when needed; see docs/data_gaps.md (source: LBI database (defunct) via Wayback Machine snapshots)
